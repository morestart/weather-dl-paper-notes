# EarthNet：多模态掩码自编码器从卫星观测生成全球大气分析场

> Thomas J. Vandal、Kate Duffy、Daniel McDuff、Yoni Nachmany、Chris Hartshorn，*Global atmospheric data assimilation with multi-modal masked autoencoders*，2024-07-16 [arXiv:2407.11696v1](https://arxiv.org/abs/2407.11696)；[原文 PDF](https://arxiv.org/pdf/2407.11696)，[作者代码与数据说明](https://github.com/myzeus/earthnet)。本笔记于 2026-09-24 核对 v1 全文图 1–9、表 1–6 与补充 A–F，并目视检查结构图和表 6。原图只链接，不转载。主问题是**数据同化/观测重建**；文中仅说可生成 **1–6 小时**未来场，实际系统检验以 **1 小时背景场**为主，**没有 10–15 天中期技巧**。

## 一、研究问题与证据边界

多数深度学习全球预报器仍从业务分析/再分析起报，而业务分析需要复杂的观测算子、物理模型与变分优化。EarthNet 提出另一条入口：直接把不同轨道和光谱的卫星资料、卫星反演产品以及地形放进共同的时空掩码学习任务，预测各模态中未观测的部分，并将 MiRS 温湿廓线稀疏采样扩展成全球完整格点。作者称之为“data assimilation”，本质上是**观测条件化的多模态填补/状态估计**，并未在业务 4DVar 同一控制量、代价函数和误差协方差协议下做等价求解。[论文第 2–4 页及补充 B–C](https://arxiv.org/pdf/2407.11696)

“只从观测训练”需精确定义：没有以 ERA5/MERRA-2 作训练标签，原始亮温/辐射来自多种卫星；但输出目标之一 MiRS 是**先经辐射传输和 1DVar 反演的温湿度产品**，不是原始亮温或独立探空真值。故 EarthNet 对 MiRS 的接近既是观测信息融合能力，也反映其学习了 MiRS 产品的误差特征。ERA5/MERRA-2 和探空只在验证中出现，不能说模型完全不接触任何物理反演。[补充 A.1.6、图 4、表 6](https://arxiv.org/pdf/2407.11696)

| 模态 | 轨道与输入角色 | 原文所列通道、处理要点 |
| --- | --- | --- |
| GOES-16/18 ABI | 美洲两侧静止轨道，L1b 亮温/辐射 | 各选热红外 **7–16 共 10** 通道；原始 0.5–2 km、1–10 min，插值/重投影后降至公共格。 |
| GEO-KOMPSAT-2A AMI | 东半球静止轨道，KMA L1B | 同取 **7–16 共 10** 热红外通道。 |
| SEVIRI | 欧洲/非洲静止轨道，EUMETSAT | 数据段写 **8** 个红外波段；附表 3 列出 **9** 个通道名，版本内不一致。 |
| VIIRS | NOAA-20/Suomi-NPP 极轨影像；文中具体下载项是 `VNP02MOD` | 附录列 `M08、M10–M16`，逐个数为 **8** 个；表 1 却写 **7**。原始约 750 m、6 min 颗粒，降采样至约 16 km。 |
| ATMS | NOAA-20 与 Suomi-NPP 极轨微波探测 | **22** 亮温通道；L1b 每 6 min 颗粒，应用 limb correction，双星在公共格重复覆盖处取平均。 |
| SRTM | 静态条件 | 地形高度与海陆掩码；不具有 12 小时时轴。 |
| MiRS 温度、比湿 | 卫星反演的两项训练输出模态 | 各 **37** 气压层，MiRS 本身经辐射传输与 1DVar；资料可用期 2023-09–2024-03，但训练只用至 **2024-01**。 |

全体数据投影为 **0.16°** 经纬网，附录给格点形状 **1125×2249**；原始观测按最近整点归档，形成**逐小时**格点合成，12 小时连续切片喂给模型。公共分辨率受 ATMS 约 16 km 约束，约 **500 TB** 源数据处理成 **2 TB** 训练数据。四颗静止卫星合计约覆盖 60% 格点，单个极轨约 10%，ATMS 双星约 20%；剩余区域/时次没有观测时保持缺测并在学习与推理中掩码，不应把“逐小时合成”理解为每个传感器每小时全球满覆盖。[正文第 3 页、补充 A.1](https://arxiv.org/pdf/2407.11696)

训练基座用 **2022–2023** 的非 MiRS L1 资料；温湿 MiRS 数据加入时使用 **2023-09–2024-01**，完整独立测试保留 **2024-02–03** 两个月。探空验证来自 IGRA 约 2800 个站的数据档案，在同一两个月与四套产品配对；探空未给 EarthNet 训练，但 ERA5/MERRA-2 业务系统会吸收探空，因此它不是对四套方法完全对称的独立真值。[补充 D、A.2、E.2](https://arxiv.org/pdf/2407.11696)

公开附录还说每个模态归一化到 **均值 0、标准差 1**，但**未列各通道的均值/标准差数表、缺测质量控制的全部规则、投影插值核与对海陆异常值的处理**。复现时必须从公开处理代码或原始数据重新核验，不能给它套用 ERA5 字段统计量。[补充 C](https://arxiv.org/pdf/2407.11696)

## 三、网络结构与推理：九模态任意条件到任意输出

每个 12 小时切片被切为 **144×144** 空间小图，时变模态按 `1×16×16` 时空 token 化，静态地形按 `16×16`。九个模态各有专属编码器和解码器；每个编码器先用 2D/3D 卷积做 patch token，再接 **6 头** Transformer block，送出共同 **768 维** token。所有模态 token 与一个全局嵌入拼接后进入**12 层、12 头**共享 Transformer；缺测 token 设为掩码，不让无效值作为证据。解码侧每模态接入其他模态上下文，跨模态上下文嵌入 **384 维**，由 **6 层、8 头** decoder 重建完整图场。[补充 C.1–C.3、图 1](https://arxiv.org/pdf/2407.11696)

```mermaid
flowchart LR
  O["逐小时卫星亮温、MiRS 温湿廓线、SRTM\n12 小时窗口；0.16° 公共格"] --> P["空间裁块 144×144\n按模态 2D/3D、16×16 token"]
  P --> E["9 组模态专属编码器\n共同 768 维"]
  E --> M["随机选 128 个有效 token\n共享 Transformer：12 层/12 头"]
  M --> D["模态专属 decoder\n6 层/8 头；跨模态上下文"]
  D --> S["补齐观测与 37 层温湿度\n滑窗 + Hann 权重拼接"]
  S --> V["留出最后 1 小时输入\n生成背景场并与观测比较"]
```

此图据[原文图 1、补充 C 与 E](https://arxiv.org/pdf/2407.11696)原创重绘。全球推理不是把 `1125×2249` 整图一次放进 GPU：作者以移动窗口对小图逐块预测，再用 Hann 窗权重合并重叠区。补充 E 指实际验证把每天分为 `[00,12)` 与 `[12,24)` 两个**不重叠**时段；窗口头尾时间上下文较少，误差会升高。图 5 报这种 12h 块边缘效应相对 MERRA-2 比较尺度约占温度误差 **2.5%**、相对湿度 **1.2%**。[图 1、图 5 与补充 E.2](https://arxiv.org/pdf/2407.11696)

## 四、完整训练流程、优化参数与“微调”到底发生在哪里

1. **每模态预训练编码/解码器**：采用高斯潜变量 VAE，KL 权重 **1e−4**；单卡训练各模态所需约 **12–24 小时**。论文没有逐个模态发布 VAE 层数、参数量、学习率或 batch；不能由总体基座超参倒填到这一步。[补充 C.1、D](https://arxiv.org/pdf/2407.11696)
2. **基座联合掩码训练**：使用 2022–2023 的非 MiRS 多源资料，**16×NVIDIA V100** 约 **两周**。每模态可用 token 比例通过 Dirichlet 抽样，约 **8752** token/样本中只有约 **1750** 完整有效，最终随机保留 **128** 个作为输入，约占全样本 **1.4%**；其余有效而被掩码的 token 用重建 MSE 训练。附录另将“丢弃 98.6%”按全 token 计，这不同于在有效 1750 个里只保留 128 个的约 92.7% 掩码比例，百分比口径不可混用。[正文第 4 页、补充 D.1](https://arxiv.org/pdf/2407.11696)
3. **加入 MiRS 后继续训练**：从 2023-09–2024-01 的可用 MiRS 温湿度模态接续同一掩码目标，使网络学会由其他传感器条件化重建 37 层廓线。全文把三阶段总训练称为约 **21 天**，但**未把最后阶段确切天数、学习率、批大小、梯度裁剪、权重衰减、随机种子、总更新步数或各层是否冻结**逐项公布；这一步只能称继续训练/产品接入，不能擅写成已验证的特定 LoRA/全参微调配方。[正文第 4 页、补充 D](https://arxiv.org/pdf/2407.11696)

补充 D.2 明确主训练优化器为 **Adam，β₁=0.5、β₂=0.9**，损失只在**有实际观测且被掩码**的位置计算 MSE；既不把缺测 NaN 当零真值，也不把探空/ERA5 引入监督。推理时参数冻结，所谓“同化”是依条件重新生成分析，不是每次为新观测做模型参数微调。论文未报可复验的模型总参数量和单次全球分析耗时，因此正文“计算成本远低于业务系统”属方向性主张，不能从本文数字推算标准化加速倍率。[补充 D.2、正文讨论](https://arxiv.org/pdf/2407.11696)

## 五、图表、数值结果与反面证据

### 5.1 一小时背景场与传感器消融

“背景”测试把输入各模态的**最后一帧移除**，由前 11 小时及其他模态预测第 12 小时，然后只与当时未输入的观测算差。这比拿已经见过的分析场与同一观测算误差更接近预报检验；不过正文未给 2–6h 完整性能曲线，不能把“能生成 1–6h”升级成六小时优于 NWP 的证明。[正文第 5 页、补充 E.1](https://arxiv.org/pdf/2407.11696)

| 原文图/表 | 可核验现象 | 解读界限 |
| --- | --- | --- |

| --- | --- | --- |
| 925 hPa | **2.38 / 2.61 / 0.87 / 0.62** | **18.58 / 16.91 / 10.39 / 7.59** |
| 500 hPa | **1.56 / 1.58 / 0.59 / 0.40** | **15.17 / 13.21 / 15.97 / 14.69** |
| 250 hPa | **2.61 / 2.80 / 0.82 / 0.54** | **8.04 / 8.49 / 22.03 / 12.13** |
| 100 hPa | **1.55 / 1.71 / 0.68 / 0.61** | **2.47 / 2.30 / 5.96 / 6.00** |
| 50 hPa | **1.37 / 1.29 / 0.79 / 0.71** | **0.66 / 0.70 / 1.01 / 1.06** |

因此“湿度在 50–500 hPa 优于两大再分析”主要指图 4/表 6 的**部分中高层**：如 250 hPa EarthNet **8.04** 明显低于 MERRA-2 **22.03**、ERA5 **12.13**。但 500 hPa 对 ERA5 **14.69** 并无优势，低层 925/850/700 hPa 相对湿度明显更差；全层平均 EarthNet **8.33** 也**高于 ERA5 7.67**。温度全层 EarthNet **1.92 K** 大幅高于 ERA5 **0.64 K**；正文另报告温度相对再分析平均多 **1.28 K（ERA5）/1.11 K（MERRA-2）**，正与表 6 相符。不能只转述摘要的“10–60% lower”而不列低层和温度的反例。[正文第 6–7 页、表 6](https://arxiv.org/pdf/2407.11696)

正文图 4 的探空气温相关系数 EarthNet/MiRS 约 **0.94**，ERA5/MERRA-2 **>0.99**；相对湿度方面 EarthNet 作者报总体 MAE **8.337%**，ERA5 **7.746%**，MERRA-2 **9.937%**，并强调 EarthNet 湿度偏差小于 1%、再分析约 6–7%。这些数字和表 6 平均列 **8.33/7.67/9.83** 有细微差异，可能来自正文与表格的样本/舍入口径，但论文未解释，故不强行合并。[正文第 7 页、表 6](https://arxiv.org/pdf/2407.11696)

### 5.3 原文自相矛盾或无法复核处

- **附表 5 的明显排版错误**：标题是“MiRS specific humidity”，但 37 行数值与温度附表 4 **逐行完全相同**，单位栏仍写 K。不能把这些复制的数字当作比湿 MAE 训练/验证证据；本笔记只引用经目视核验的表 6 相对湿度结果。[附表 4–5](https://arxiv.org/pdf/2407.11696)
- **通道计数不一致**：表 1 写 VIIRS 7、SEVIRI 8；附录 A.1.4 明列 VIIRS 八个 M 波段，附表 2 也列八个；附表 3 对 SEVIRI 列九个通道。具体实现应以数据文件/代码的 channel map 再核，不能凭任一表无条件确定网络通道总数。[表 1、附录 A、附表 2–3](https://arxiv.org/pdf/2407.11696)
- **统计标记文字矛盾**：表 6 图注把星号解释为“与 MiRS 差异不显著”，同时写 `p<0.05`；若这是普通差异检验，`p<0.05` 通常表示显著。全文未给出检验方法、样本独立性和多重比较校正，故不引用星号证明严格“统计等价”。[表 6](https://arxiv.org/pdf/2407.11696)
- **真值公平性**：探空对 EarthNet 是留出数据，对 ERA5/MERRA-2 可能是其同化输入；而 EarthNet 的 MiRS 目标又含物理反演。此比较能显示产品误差结构差异，但不足以单独证明一种方法在相同观测集合和计算预算下全面替代业务 DA。[正文第 6–7 页、补充 A/E](https://arxiv.org/pdf/2407.11696)

## 六、与“观测到中期预报”的关系及复现路线

EarthNet 填上了“真实多卫星观测→稠密温湿分析场”的研究链条，与以 ERA5 伪观测作同化的 [4DVarFormer](72-4dvarformer.md) 和 [Tensor-Var](71-tensor-var.md) 证据层级不同；但它**没有公开把其分析场作为全球 10–15 天 AI 预报器初值并评估增益**。它与 [FuXi-DA](69-fuxi-da.md) 也不同：FuXi-DA 用 FY-4B 单颗静止卫星亮温与 FuXi 背景场做有监督订正并测试后续 FuXi 预报；EarthNet 则从九模态中掩码建模、生成全球分析，不依赖 ERA5 背景场作输入。不能把两篇的预报时效、性能或数据独立性互相嫁接。

若想使论文成为真正的观测直达中期系统，至少需要：① 固定训练、验证、测试在跨年和跨卫星漂移上的无泄漏划分，公布清洗/插值/逐通道统计量；② 补齐附表 5 与通道数错误，并发布参数量、完整学习率、batch 和接入 MiRS 阶段的冻结/更新方案；③ 用同一批未同化的探空/飞机/卫星检验分析场，尤其检查低层湿度和温度负例；④ 把 EarthNet 分析初值送入相同的 10–15 天确定性或集合预报器，与 ERA5/业务初值作成对、同观测信息量的回报试验；⑤ 报告重叠滑窗的**整球单次分析耗时**、显存和高纬/极区的有效分辨率，而非只说“更快”。这些是本笔记提出的**后续实验建议**，不是论文已经完成的实验。
